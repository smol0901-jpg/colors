# Презентация: коррекция цвета и контроль производства

Статический сайт для GitHub Pages (без сборки).

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки в корень (index.html и папка img).
2. Settings, затем Pages, затем Source: Deploy from a branch, ветка main, папка / (root).
3. Через 1–2 минуты сайт откроется по адресу https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

Контакты и тексты правятся прямо в index.html.

Новое: секция «Воронка» (3D на чистом WebGL, без внешних библиотек), секция «Оборудование» (скриншоты демо), два скриншота для продакшена в блоках «Что это даёт» и «Комплексная система». Рендеры: папка img/render (WebP, MP4). Демо лежит в папке demo (вкладка «Ещё» → «Оборудование в разрезе»).

## Страница агента

`agent/index.html` — отдельная страница «ИИ-агент контроля линий» (без сборки, чистый JS): 5 линий, лента событий, консоль с «размышлением» агента, анализатор (вибрация, зоны, шнеки, камера, прогноз, цена бездействия), сценарий показа, журнал с выгрузкой CSV. Логика (`agent/agent-core.js`) собрана из TypeScript-версии проекта colors-site-v2, кадры камер — `img/agent/`.

В демо добавлены вкладки «Визуальный контроль» (камера, вкрапления, тепловизор, лазер) и «Мощность и масштаб». Фото оборудования лежат в `img/equipment/` (вкладки «Фото»).

## PWA

Сайт устанавливается как приложение (Android/ПК: кнопка «Установить приложение», iOS: «Поделиться → На экран Домой») и работает офлайн: `manifest.webmanifest`, `sw.js`, `pwa.js`, иконки в `icons/`. Пути относительные, подходит для GitHub Pages в подпапке. **При каждой публикации меняйте `VER` в `sw.js`** (например `cik-v2`), иначе у посетителей останется старый кэш.

## Программа и экспертиза

`program/index.html` — страница «Программа под ваше производство»: для чего, что нужно, чем поможет, калькулятор выгоды (потери, эффект, окупаемость по месяцам), помощник с готовыми вопросами, варианты подключения. Допущения эффекта в `program/program.js` (объект `SCN`). Раздел «Экспертиза» — в `index.html`, блок `#expertise`.

## Коррекция цвета

`correction/index.html` — инструмент: по L*a*b* эталона и образца (или отклонению с прибора), размеру замеса/пробы и содержанию пигмента считает добавки (для готового замеса только плюс; для рецепта следующего замеса можно и минус). Типовые чувствительности колорантов — в `correction/correction.js` (массив `COL`), в браузере их можно откалибровать по своим пробным добавкам. Реальные рецептуры, марки сырья и данные производства в код не включены.
