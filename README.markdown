# Презентация: коррекция цвета и контроль производства

Статический сайт для GitHub Pages (без сборки).

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки в корень (index.html и папка img).
2. Settings, затем Pages, затем Source: Deploy from a branch, ветка main, папка / (root).
3. Через 1–2 минуты сайт откроется по адресу https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

Контакты и тексты правятся прямо в index.html.
