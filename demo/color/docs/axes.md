# Оси CIE L*a*b* для порошковых красок

## L* — светлота
- 0 = абсолютный чёрный
- 100 = идеальный белый
- ΔL* > 0 → образец светлее эталона → добавлять чёрный / уменьшать белый
- ΔL* < 0 → образец темнее → добавлять белый (TiO₂) / уменьшать чёрный

## a* — ось красный–зелёный
- +a* = красный
- −a* = зелёный
- Δa* > 0 → образец краснее → добавлять зелёный пигмент
- Δa* < 0 → образец зеленее → добавлять красный пигмент

## b* — ось жёлтый–синий
- +b* = жёлтый
- −b* = синий
- Δb* > 0 → образец желтее → добавлять синий пигмент
- Δb* < 0 → образец синее → добавлять жёлтый пигмент

## ΔE*ab
Евклидово расстояние в пространстве L*a*b*:

ΔE = √( (ΔL*)² + (Δa*)² + (Δb*)² )

Типичные допуски для порошковых покрытий:
- ΔE < 0,5 — отличное совпадение
- ΔE < 1,0 — коммерчески приемлемо
- ΔE 1–2 — заметно, нужна коррекция
- ΔE > 2 — значительная разница

## На графике в программе
- Вверх = +b* (жёлтый)
- Вниз = −b* (синий)
- Влево = −a* (зелёный)
- Вправо = +a* (красный)
