# Рабочий процесс коррекции цвета

## 1. Подготовка
- Откалибровать спектрофотометр (белый/чёрный эталон по инструкции прибора)
- Подготовить выкраски эталона и образца в одинаковых условиях (толщина, температура отверждения, время)

## 2. Измерение
1. Измерить эталон → записать L*, a*, b*
2. Измерить образец → записать L*, a*, b*
3. Ввести значения в программу

## 3. Анализ
- Смотреть ΔE — нужно ли корректировать
- Смотреть знаки ΔL*, Δa*, Δb* — направление
- Смотреть график a*/b* — визуально
- Читать блок «Что добавить»

## 4. Коррекция
- Добавлять пигмент **очень малыми** порциями (0,01–0,1 % от массы партии)
- Тщательно перемешать (для порошка — часто через экструзию)
- Сделать новую выкраску
- Снова измерить

## 5. Повтор
Повторять цикл, пока ΔE не войдёт в допуск (обычно ≤ 1,0–1,5).

## Особенности порошковых красок
- Цвет порошка ≠ цвет после отверждения
- Металлики и текстуры требуют особого внимания к геометрии измерения
- Разные партии пигментов могут чуть отличаться
- История замеров в программе помогает отслеживать прогресс коррекции
