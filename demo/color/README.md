# Коррекция цвета · DEMO v0.4.0

Покажите пальцем на графике, где образец относительно эталона, — программа скажет, **какой колорант и сколько % добавить** (и сколько это граммов на вашу партию).

## Как пользоваться
1. **Эталон** — введите L*a*b* с прибора или выберите RAL (поиск или справочник внизу). Эталон всегда в центре графика.
2. **Образец** — коснитесь графика (a*, b*) и полосы справа (светлее/темнее, L*), либо введите цифры с прибора.
3. Смотрите карточку **«Что добавить»**: колорант, %, масса. Первый шаг — 50 % от расчёта (переключается на 75/100 %).
4. Добавили → замерили → ткнули новый образец → повторили, пока ΔE не войдёт в допуск.
5. Чтобы расчёт стал точным под вашу базу — блок **«Обучение по пробной добавке»**.

Оси: вверх жёлтый (+b*), вниз синий (−b*), влево зелёный (−a*), вправо красный (+a*). Масштаб графика — от ±0,1 до ±100: кнопки, ползунок (логарифмический) или своё число. Для малых разниц берите мелкий.

## Под прибор BYK spectro2guide
- Блок **«Прибор»**: модель/геометрия (45/0, d/8 SCI/SCE, spectro-guide) и источник/наблюдатель (D65/10° и др.). Сохраняется в браузере и пишется в историю.
- Режим **«Δ с экрана прибора»**: вводите ΔL*, Δa*, Δb* как на экране (образец минус эталон), эталон можно взять из RAL.
- **Быстрый ввод**: вставьте строку с числами из прибора/smart-chart — первые три числа уйдут в эталон, образец или Δ.
- Показываются ΔL*, Δa*, Δb*, ΔC*, ΔH*, ΔE*ab, ΔE00, ΔE CMC 2:1; допуск проверяется по выбранной формуле.
- Блеск 60° (GU) для эталона и образца: показывается ΔGloss и предупреждение при большой разнице.

## Расчёт дозы по ТТК
Заполните блок «Рецептура (ТТК)» — % каждого пигмента в замесе. Масса для коррекции — по регламенту (1, 10 кг и т. д.).
Грамм к добавлению = **масса × % пигмента в ТТК × % добавки**. Например: 1000 г × 3 % × 10 % = 3 г. Формула видна в каждой строке.

## Нейро-подсказка (демо)
Малая нейросеть в браузере предсказывает, как каждая краска сдвигает цвет (с учётом насыщения и состояния базы). Планировщик подбирает дозы и **неполный** первый шаг: убрать краску нельзя, поэтому перебор хуже недобора. Цель — 1–2 корректировки, максимум 3.
Рабочий цикл: «Добавил» → замер на приборе → «Обучить и пересчитать». Программа сверяет результат с прогнозом и уточняет **силу каждой краски** (× сила), следующий шаг становится смелее.
В продукте советы пойдут через LLM (Claude, Grok, Qwen, DeepSeek, Kimi, GigaChat) по серверному шлюзу; в демо есть кнопка копирования готового запроса.

## Как считается
Линейная модель: сдвиг цвета = Σ (доза_i × сила_i), сила — ΔL*, Δa*, Δb* на 1 % колоранта. Подбираются только положительные дозы из 1–3 колорантов. Стартовые силы **ориентировочные** — откалибруйте. Реальные системы нелинейны, поэтому большие дозы делите на шаги.

```
index.html · css/style.css · assets/
js/lab.js        Lab → RGB, ΔE

js/dosing.js     расчёт доз и форматирование (0,0001 %…)
js/plot.js       интерактивный график a*/b* и полоса L*
js/ral-data.js   RAL Classic: 190 цветов с L*a*b*, поиск по коду
js/history.js    история замеров
js/app.js        логика
```
